# Contributing to Taurus

Thank you for contributing!

## Development Guidelines

- Keep changes focused and maintainable.
- Follow existing Java and Spring Boot conventions.
- Add or update tests when changing application behaviour.
- Never commit passwords, API keys, or environment secrets.
- Document important API and architecture changes.

## Pull Request Guidelines

Every pull request should include:

- A clear summary of the changes.
- The reason for the changes.
- Relevant test results.
- Any known limitations.
